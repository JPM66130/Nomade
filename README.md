# Nomade – API

![Tests](https://github.com/JPM66130/Nomade/actions/workflows/test-app.yml/badge.svg)

API Nomade – données stations, spots, parkings, alertes et itinéraires.

## Tests automatisés
Les tests sont exécutés automatiquement via GitHub Actions :
- Tests d’erreurs (404, 422)
- Tests de filtres
- Tests de performance
- Tests de structure JSON
- Tests de valeurs invalides
- Tests de routes inexistantes
